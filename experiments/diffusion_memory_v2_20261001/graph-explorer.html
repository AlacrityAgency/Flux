حافظه‌ای که رابطه را همراهِ منبع نگه می‌دارد

دو بلوک، یک مینی‌بلوک مشترک دارند. متنِ هر شاهد یک بار ذخیره می‌شود و ارتباط از reference استفاده می‌کند. این نمایش از دادهٔ benchmark ساخته شده است.

شاهدِ اول

مینی‌بلوک مشترک
referenceهای دو طرف، نوع رابطه و ارزش اتصال. رابطهٔ غایب هنگام query از ایندکس همان پروژه یادآوری می‌شود.
شاهدِ دوم


ماتریس و ترکیب ارزش
اسلایدرها فقط ارزش نگه‌داریِ نمایشی را تغییر می‌دهند. کفایت معنایی، نتیجهٔ آزمون و اهمیت سازمانی از آن به دست نمی‌آید.
ویژگیشاهد اولشاهد دوم


اشتراک در یک پروژه است. کد اشارهٔ متنی به نام symbol را تشخیص می‌دهد؛ آن را call graph یا اجرای واقعی تلقی نکنید. سقف گراف شامل metadata است، اما آرشیو و ایندکس بیرونی همچنان باقی می‌مانند. هیچ مدل یا وزنی اینجا آموزش نمی‌بیند.
