# Flux Demo — فضای شخصی پنج Agent

نسخهٔ ۰٫۲: رابط گفت‌وگومحور فارسی، تاریخچهٔ محلی، پنج نقش Agent، حافظهٔ قابل مدیریت و دفتر مصرف. این نسخه برای استفادهٔ شخصی روی Windows است. حالت پیش‌فرض آزمایشی است؛ نمونه‌های fake پاسخ مدل واقعی نیستند.

## اجرا

**نسخهٔ Windows:** فایل `dist/economy/Flux.exe` را برای نسخهٔ دارای سطح مصرف Low/Medium/High باز کنید. برنامه در پنجرهٔ مستقل Edge/Chrome با سرویس محلی اجرا می‌شود. دادهٔ نسخهٔ بسته‌بندی‌شده در `%LOCALAPPDATA%\FluxDemo` ذخیره می‌شود. Edge یا Chrome باید نصب باشد؛ در غیر این صورت مرورگر پیش‌فرض باز می‌شود.

**از سورس:**

```powershell
python -m pip install -e ".[dev]"
python run_flux.py
```

برای اجرای رابط در مرورگر معمولی با پورت ثابت:

```powershell
python run_flux.py serve --host 127.0.0.1 --port 8040
```

در حالت سورس، دیتابیس پیش‌فرض `var/flux.db` است. متغیر `FLUX_DB_PATH` مسیر آن را تغییر می‌دهد. دادهٔ قدیمی حذف نمی‌شود و Runهای قدیمی به تاریخچهٔ گفت‌وگو اضافه می‌شوند. از اجرای هم‌زمان چند سرویس با یک دیتابیس خودداری کنید؛ لانچر پنجره‌ای برای پوشهٔ داده قفل تک‌نمونه دارد.

## استفاده

1. یکی از سه نمونه را انتخاب کنید یا هدف خود را بنویسید.
2. در تنظیمات کنار ورودی، معیار پذیرش و سقف هزینهٔ این پیام را مشخص کنید.
3. کنار ارسال سطح مصرف را انتخاب کنید: Low (پیش‌فرض) همهٔ نقش‌ها را با Luna و سقف ۱۶۰۰ تا ۲۰۰۰ توکن اجرا می‌کند؛ Medium فقط نقش فنی را به Sol می‌سپارد؛ High مسیر کامل پنج نقش با مدل‌های قبلی و سقف بالاتر است. Low یک زیرکار متمرکز درخواست می‌کند؛ بازبینی مستقل در همهٔ سطح‌ها حفظ می‌شود. تنظیمات قدیمی auto/team برای داده‌های قبلی پشتیبانی می‌شوند.

سقف انتخابی توکن بدون افزایش یا تعویض پنهان مدل به ارائه‌دهنده ارسال می‌شود. تعرفه‌های محلی تخمینی‌اند؛ کاهش هزینهٔ واقعی به usage و تعرفهٔ GapGPT بستگی دارد.
4. نتیجه، منابع و مصرف را ببینید؛ پاسخ را کپی یا دریافت کنید، بپذیرید یا پیام اصلاحی بفرستید.
5. اطلاعات مفید را با انتخاب خودتان در حافظه ذخیره کنید. یادداشت‌ها از صفحهٔ حافظه ویرایش و حذف می‌شوند.

Enter ارسال، Shift+Enter خط جدید و Ctrl+K گفت‌وگوی جدید است. پیوست‌های این نسخه فقط فایل متنی‌اند. هر پیام سقف خودش را دارد و سقف روزانه در صفحهٔ مصرف تنظیم می‌شود. عدد مصرف fake، صورتحساب واقعی نیست.

## اتصال واقعی

شناسه‌ها، قابلیت JSON، usage و قیمت پنج مدل هنوز با GapGPT تأیید نشده‌اند. کلید فقط از `GAPGPT_API_KEY` در محیط پردازش خوانده می‌شود؛ آن را داخل فایل، پیام، حافظه یا Git قرار ندهید. با `FLUX_ENABLE_LIVE=1` یا گزینهٔ `--live` اتصال واقعی انتخاب می‌شود. پیش از استفادهٔ واقعی تعرفه و دسترسی مدل‌ها را بررسی کنید؛ نرخ‌های فعلی تخمین‌های فهرست اولیه‌اند و تضمین سقف صورتحساب خارجی نیستند. هیچ کلیدی همراه برنامه بسته‌بندی نشده است.

حافظه و تاریخچه محلی‌اند؛ در حالت زنده فقط context منتخب و ورودی کار به GapGPT فرستاده می‌شود. فونت و دارایی‌های UI محلی‌اند و CDN ندارند.

این ابزار در دیتابیس سرویس مقصد گفت‌وگو و یادداشت آزمایشی می‌سازد؛ برای تست از `FLUX_DB_PATH` جدا استفاده کنید. محیط `.venv-ui` ابزار توسعه است و جزو وابستگی اجرایی نیست. تصاویر بررسی رابط در `docs/screenshots` هستند.

## محدودیت‌ها

- این دمو shell یا کد تولیدشده را اجرا نمی‌کند؛ خروجی کد، پیشنهاد است و تست اجرا نشده passed نیست.
- حافظه جست‌وجوی واژگانی دارد؛ embedding، همگام‌سازی ابری، چندکاربره و اتصال Alacrity OS ندارد.
- اصلاح با پیام جدید انجام می‌شود؛ resume کور تماس نامعلوم و اصلاح خودکار نامحدود وجود ندارد.
- حذف یادداشت مانع بازیابی آینده می‌شود؛ snapshot آن در تاریخچهٔ اجراهای قبلی حفظ می‌شود.
- سقف روزانه بر اساس UTC/روز ایجاد Run است. هزینهٔ usage ناموجود به‌صورت unknown نگه داشته می‌شود.
- فایل اجرایی امضای دیجیتال ندارد؛ نسخهٔ اولیهٔ شخصی است.

## نوار مصرف و تیم دلخواه

روی Low کنار ارسال بزنید تا نوار Low / Medium / High باز شود. دکمهٔ بازنشانی سطح را به Low برمی‌گرداند. از «تنظیم Agentها و مدل‌ها» یا دکمهٔ مدیریت در پنل Agentها، مدل نقش‌های اصلی را تغییر دهید و حداکثر پنج Agent اضافه بسازید.

هر Agent اضافه نام، نقش، مدل، دستور کار و کلید فعال/غیرفعال دارد؛ تغییرات با «ذخیرهٔ تغییرات» ثبت می‌شوند. مدل «طبق سطح مصرف» از نوار پیروی می‌کند؛ مدل صریح با جابه‌جایی نوار عوض نمی‌شود. Agentهای اضافه به ترتیب، خروجی مراحل قبلی را دریافت می‌کنند و قبل از بازبین نهایی اجرا می‌شوند. همهٔ تماس‌ها و هزینه‌ها در دفتر مصرف ثبت می‌شوند و سقف بودجه پابرجاست.

تنظیمات تیم در دیتابیس محلی ذخیره و برای هر اجرای جدید snapshot می‌شوند؛ ویرایش بعدی تیم تنظیمات اجراهای قبلی یا در حال اجرا را تغییر نمی‌دهد. مدل‌ها از فهرست موجود GapGPT در برنامه انتخاب می‌شوند؛ دسترسی واقعی آن‌ها به حساب ارائه‌دهنده بستگی دارد.
