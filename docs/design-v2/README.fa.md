- `03-10-workspace.html?screen=3`: صف/کانبان، فیلتر Head و ۱۲ وضعیت
- `03-10-workspace.html?screen=4`: نسخه، شاهد، ایراد، هزینه، بازبین و مسیر هفت‌مرحله‌ای تصمیم

- `03-10-workspace.html?screen=6`: دفتر مصرف، رزرو و هزینهٔ خروجی پذیرفته‌شده

- `03-10-workspace.html?screen=8`: شرکت، بخش، پروژه و کار جاری
- `03-10-workspace.html?screen=9`: گفتگوی متصل به گره، شواهد و فعالیت ابزار
- `03-10-workspace.html?screen=10`: وضعیت اتصال‌ها و تنظیمات

از Flux دسکتاپ، «میز سازمان Alacrity» را باز کن. داده‌های صفحات ۱ تا ۹ نمونهٔ قابل تعامل طراحی هستند، نه دادهٔ زنده و نه همهٔ آن‌ها عملیات سمت سرور دارند. صفحهٔ اتصال‌ها وضعیت ارائه‌دهنده‌ها را از `/api/local/status` می‌خواند و کلیدها را نمایش نمی‌دهد. صفحهٔ درخواست از برگهٔ قرارداد تا زمان اتصال به موتور HEAD، فقط پیش‌نمایش طراحی است.

این فایل‌ها در EXE از `flux/design-v2` سرو می‌شوند. مسیر `/design-v2/*` سیاست CSP محدودشده به همان میزبان دارد تا صفحه‌های طراحی درون‌برنامه اجرا شوند.

## رفتار ویندوزی و حذف API

- `static/native.js` و `native.css` در همهٔ صفحه‌ها بارگذاری می‌شوند: کلیک راست منوی فارسی شبیه Windows 11 دارد (واگرد، برش، کپی، چسباندن، حذف، انتخاب همه؛ روی پیوند «باز کردن/کپی نشانی»؛ روی صفحه «بازگشت/بارگذاری مجدد»). منو با صفحه‌کلید و Escape کار می‌کند و داخل dialogها هم باز می‌شود. در حالت برنامه، F12 و Ctrl+U/S بسته‌اند و رها کردن فایل روی پنجره صفحه را عوض نمی‌کند.
- اتصال GapGPT API حذف شده است: آداپتور، endpointها، کلید ذخیره‌شده و گزینهٔ رابط. حساب GapCode و حساب‌های متصل (Codex، Claude، NotebookLM، Gemini/DeepSeek وب) سر جایشان هستند. گزینهٔ «خودکار» فقط از حساب‌ها انتخاب می‌کند و هرگز به API نمی‌رود.
