# Benchmark provenance

`benchmark_engine.py`, `benchmark_results.json`, and the parent `BENCHMARK_REPORT.fa.md` are **simulation artifacts**. They use random token/time values and reference answers rather than calling providers. They cannot establish accuracy, savings, safety, or skill superiority.

The independent real experiment is in [`real_skill_compare_20261012`](real_skill_compare_20261012/). Its frozen plan, actual native CLI receipts, real local Laya decisions, identical final audits and results are separately retained. No parent simulation metric is used in that experiment.
