Launch Flux Workspace

Run the command below or launch directly from your Desktop shortcut.

# 1. Start the Flux Web & Agentic Engine
python -m flux serve --host 127.0.0.1 --port 8000

# 2. Or run desktop installer
.\Install-Flux.bat

Once started, visit http://127.0.0.1:8000 to interact with the workspace, or /attention for the multi-agent inbox.
